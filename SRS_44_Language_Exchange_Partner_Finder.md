# Software Requirements Specification (SRS)
## Project 44: Language Exchange Partner Finder (Education)

### 1. Project Description
The Language Exchange Partner Finder is a language learning platform that connects individuals who want to practice speaking a foreign language with native or fluent speakers of that language who, in turn, want to learn the first user's native language. This mutual practice model — where each session involves alternating between both languages — eliminates cost barriers to conversation practice and provides authentic, real-world language exposure that formal courses cannot replicate.

### 2. Core Scope
The application focuses on preference-based partner matching, session scheduling, integrated communication tools, progress tracking, and a structured session format to ensure both languages receive equal practice time in each exchange session.

### 3. Functionalities (Minimum 25)

#### User Profile & Language Setup
1. **Profile Creation:** Register with name, profile photo, location/timezone, age, and a brief bio.
2. **Native Language Declaration:** Specify the user's native language(s).
3. **Target Language & Proficiency Level:** Select the language the user wants to learn and self-assess their current proficiency level (A1–C2 on the CEFR scale).
4. **Multiple Language Pairs:** Support users who want to practice more than one language simultaneously, creating multiple exchange profiles.
5. **Interests & Topics:** List personal interests and preferred conversation topics (e.g., Travel, Technology, Cooking, Music, Film) to improve partner compatibility.

#### Partner Matching
6. **Automatic Match Recommendations:** Algorithm finds compatible partners whose native language is the user's target language and vice versa.
7. **Compatibility Scoring:** Score potential partners based on language pair match, proficiency balance, timezone overlap, and shared interests.
8. **Filter by Timezone/Availability:** Filter partner suggestions by compatible time zones to ensure scheduling is feasible.
9. **Filter by Learning Goals:** Match partners with similar learning goals (casual conversation, exam preparation, professional communication).
10. **Partner Browse Mode:** Manually browse and search partner profiles beyond AI recommendations.

#### Connection & Communication
11. **Partner Connection Request:** Send a connection request with a personalized introduction message to a potential partner.
12. **Accept/Decline Connections:** Potential partners can accept or decline connection requests.
13. **In-App Chat Messaging:** Real-time text messaging between connected partners for casual coordination and language practice.
14. **Inline Translation Tool:** A built-in translation button within the chat to look up the meaning of a word or phrase sent by the partner.

#### Session Scheduling & Conduct
15. **Session Scheduling System:** Schedule formal exchange sessions directly within the app with proposed date, time, and duration.
16. **Calendar Reminders:** Automated email and push notification reminders before each scheduled session.
17. **Integrated Video Call:** Launch a video call directly within the platform or generate a Google Meet/Zoom link from the session card.
18. **Session Timer:** An in-session timer that signals when to switch languages at the midpoint of the session.
19. **Session Notes Section:** A shared notepad within the session for writing down corrections, new vocabulary, and phrases to remember.

#### Progress & Feedback
20. **Post-Session Vocabulary Log:** Add new words and phrases learned during a session to a personal vocabulary journal.
21. **Post-Session Feedback Exchange:** Rate the session and provide constructive feedback on the partner's language use and session conduct.
22. **Partner Rating & Review:** Written reviews on partner profiles highlighting qualities like patience, knowledge, and punctuality.
23. **Progress Dashboard:** Track total sessions completed, hours practiced per language, vocabulary words logged, and partner streak.

#### Community & Resources
24. **Community Language Forums:** Topic-based discussion boards where learners can post language questions and get answers from the community.
25. **Resource Library:** A curated collection of grammar guides, pronunciation tips, and cultural notes organized by language.
26. **Group Exchange Sessions:** Join multi-person language exchange groups for a more social, classroom-like practice experience.
